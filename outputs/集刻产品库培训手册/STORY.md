# STORY.md —— 集刻产品库 培训手册

## 目标与受众
- **受众**：公司内部同事（监装/预检现场人员、报告制作人），以及需要上手这套工具的新人。
- **场合**：入职/交接培训（1 小时），或发给同事自学。
- **目标**：看完能独立完成「装一个新包 → 建柜 → 导清单 → 导照片 → 治理 → 出报告」，
  并知道数据存在哪、怎么备份、怎么升级。

## 叙事主线（为什么按这个顺序）
培训最忌讳按菜单顺序讲——那是「功能清单」，听完不知道自己什么时候用哪个。
本手册按**第一次真实上手的时间线**排：装什么 → 装完长什么样 → 怎么开始干活 →
干活中每个页面怎么用 → 出报告 → 遇到问题怎么办。读者跟着做一遍就通了。

### 第二部分 安装（3 页）
P6 **绿色免安装包：下载与解压**（支撑页）
- 拿到 `集刻产品库_绿色包.zip`（约 240 MB）
- 解压到**固定目录**（建议 D:\集刻产品库），不要放桌面/中文路径太深
- 不要解压一半就运行；不要把 exe 单独拷出来
- 配图：install_tree.png（真实目录结构）

P7 **启动：双击即可**（hero 页）
- 双击 `集刻产品库.exe` 或 `启动产品库.cmd`
- 出现黑色命令行窗口 = 程序在跑，**关掉它就等于关闭产品库**
- 浏览器自动打开 http://127.0.0.1:8765/
- 端口被占用会自动往后找，窗口里会显示实际地址
- 配图：01_containers.png（启动后真实首屏）

P8 **首次打开：先做这一件事**（支撑页）
- 顶栏右上「设置」→ 配置多模态模型（API Base / API Key / 模型名）
- 不配也能用：仍可手工关联、仍可出报告，只是照片不会自动分类/读码
- ⚠️ API Key 只存在本机 data\ 下，不要把 data 目录发给外人
- 配图：14_settings.png

P9 **六个页面各管什么**（支撑页）

### 第四部分 柜作业五步（6 页，核心）
P11 **①建柜**（支撑页）
- 柜页 →「＋ 新建柜」；柜号必填，其余可后补
- 建完出现常驻提示条，点「进入柜作业 →」
- 也可以在柜列表每行点「柜作业 →」进别的柜
- 配图：02_new_container.png

P12 **②导入清单**（支撑页）
- 从 Excel 导入货品清单到本柜
- 在这一步查看/修改品名、规格、Loading 数量、核对结论
- 品名/规格保存后写进产品库（跨柜复用）
- 配图：04_wiz_step2.png

P13 **③照片：导入 + 治理 + 浏览**（hero 页）
- 导入照片（支持标准采集格式自动认柜号/箱号）
- 治理 = 分类 → 读码 → 关联
- 配图：05_wiz_step3.png

P14 **治理面板细讲**（支撑页）
- 分类：判断这是标签/产品/清单/场景
- 读码：OCR + 大模型双重读出产品编码
- 关联：精确匹配自动挂；模糊的进「待确认」，人工点一下
- 配图：06_govern.png

P15 **④选图**（支撑页）
- 为报告的 Quantity check 区块挑每件货的代表图
- 不选也能出报告（按编码自动取一张），但选过的更准
- 配图：07_wiz_step4.png

P16 **⑤生成报告**（hero 页）
- 一键按柜生成装柜报告 docx
- 报告含：Packing list + Quantity check + 柜况/卡车照片
- 历史报告都在「报告档案」里，可下载
- 配图：08_wiz_step5.png

### 第五部分 三个资产页（3 页）
P17 **产品库：跨柜复用的资产**（支撑页）
- 同一个编码在不同柜都能复用历史照片，不用重拍
- 柜号筛选：注意「全部柜号」包含所有柜（含还没产品的空柜）
- 可筛选有照片/无照片/有待确认/无标准图
- 配图：09_products.png

P18 **照片库：浏览与逐条维护**（支撑页）
- 五档选项卡：全部/已关联/未关联/待确认关联/新产品确认
- 点开任一张：用途、关联编码、OCR 文本、大模型描述
- 监装照片还有「监装细分」（空柜/柜侧/封条/锁门/卡车头/装柜过程/其他），
  报告的柜况区块靠它选代表性照片
- 配图：11_photos.png + 15_supervision_tag.png

P19 **报告档案**（支撑页）
- 所有生成过的报告都在这，按柜归集
- 配图：13_reports.png

### 第六部分 升级与数据（3 页）
P20 **备份：只需要拷一个文件夹**（hero 页）
- 备份 = 拷走整个 `data\` 文件夹
- 换电脑 = 把 data 放到新位置，启动时指过去
- ⚠️ 原始照片不在包里（照片库是引用原目录的），换机器后要重新导入照片批次
- 配图：install_tree.png 复用 + 强调 data

P21 **升级：换新版，不丢数据**（支撑页）
- 🔴 口径以**程序自带《使用说明.txt》**为准。升级已**集成进启动脚本**
  （2026-10-10）：双击「启动产品库.cmd」会先自动备份 data\\、再升级库结构、
  再逐表核对行数，然后自动打开界面 —— 不用再单独跑升级助手。
- 正确两步：①解压到**另一个目录**（别覆盖旧的）②把旧目录的 `data\`
  **整个**拷进新目录 → 直接双击启动产品库.cmd（绿色包没 Python，靠 exe 自带
  Python 跑升级；升级助手.cmd 仅作手动可选，效果相同）
- ⚠️ **不要直接解压覆盖** —— `_internal` 里被新版本删掉的程序文件不会自己
  消失，新旧混着留一片，把程序弄乱
- ⚠️ **不要只拷 productlib.db** —— 标准图、报告、缩略图都在 `data\` 里
- 版本可在窗口标题/设置页看到

P22 **换端口 / 换数据位置**（支撑页）
- `集刻产品库.exe --port 8800` 换端口
- `集刻产品库.exe --data D:\某目录` 换数据目录
- 或环境变量 PL_HOME / PL_DB

### 第七部分 常见问题与收尾（2 页）
P23 **常见问题速查**（支撑页）
- 双击没反应 → 看黑窗口报错，多半端口被占
- 杀毒软件拦 → 未做数字签名，加信任
- 打开是 404 → 打包漏了模块，报给技术支持
- 照片路径失效 → 换机器后照片要重新导入
- 找不到某个柜 → 用顶栏下拉切柜；柜是「先建后用」

P24 **一句话记住整条主线**（hero 收尾）
- 装好 → 建柜 → 导清单 → 导照片 → 跑治理 → 出报告
- 数据在 data\，备份拷它；升级搬到新目录，别删它
