## 重新生成
```bash
# 1) 抓截图（需 8765 服务在跑）
python tools/productlib/checks/shot_for_ppt.py /tmp/ppt_shots
# 2) 改内容后重新生成 PPT
cd outputs/集刻产品库培训手册 && python build_ppt.py
# 3) 回读渲染检查版式（无需 PowerPoint）
python render_preview.py
```

## 两个踩过的坑（改脚本前先看）
1. **截图前必须关掉所有浮层**，否则后几张全蒙着上一个抽屉。
   判据要用「有没有 `.on` 类」而不是 `display` —— 抽屉靠 `transform` 隐藏，
   `display` 永远判不出来。产品详情抽屉是 `#pDetail`（不是 `#drawer`）。
   要拍抽屉本身时得 `keep_modal=True`，否则守卫会先把它关掉。
2. **生成后一定要回读渲染看版式**。`build_ppt.py` 里所有坐标是手算的，
   算错了 python-pptx 不会报错，打开才炸。`render_preview.py` 从 pptx
   读回真实坐标重画，才能看出「标题写在图里没有」这类问题。
