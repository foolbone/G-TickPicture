系统说明这套工具解决什么问题、怎么用

集刻 · 产品库是预检监装照片的事后治理与复用工具：把现场拍的大量照片自动分类、读码、关联到产品编码， 形成可检索的产品库，后续同编码的货可以直接复用历史照片，不用重拍。

1
导入照片
目录或网页上传，自动 MD5 去重、按 EXIF 时间分组，一次导入 = 一个批次。
2
跑治理
多模态分类（标识卡/产品/包装/清单/场景）→ OCR 读码 → 精确编码自动关联，模糊的进人工。
3
人工标注
认领模糊候选、确认新产品、合并裁决；标签上的品名/规格可提取后填充到产品信息。
4
产品库
每个产品的历史照片按批次归集，可裁剪标准图，一眼看出哪些批次没拍到。
5
检索与报告
粘贴货品编码 → 检索历史照片与标准图 → 导出素材包或整库落盘交付。

设计原则：自动关联只认高置信精确匹配，错关联比没关联危险；没配多模态 API 时降级为 OCR+启发式，功能变弱但不会不能用。
