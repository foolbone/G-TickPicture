### 拆分引入的 4 类 bug（都是浏览器实跑才暴露的，静态检查抓不到）
1. **main.js 漏引 5 个模块** → 它们靠 `onTab()` 注册，「没 import = 该页永远空白」。main.js 是组合根，必须侧效应 import 全部特性模块。
2. **Duplicate export of 'onEscape'** → 定义处 `export function` 又在末尾 `export {...}` 里列一次 → **整个 main.js 求值中断**，表现为「模块全 200、控制台无 error、但 window 上什么都没有」。⚠️ 这类错只在 `Runtime.exceptionThrown` 里，不在 `Log.entryAdded`，必须同时监听。
3. **`loadProducts`/`closeBatches`/`loadStats`/`stdSuggest`/`openProduct` 未定义引用** —— 机械搬迁把调用点落下 4 处。已静态检查器补上这一项。
4. **`drawerGo`（←/→ 相邻切换）整个函数被拆丢了** —— HTML 里按钮还在，没人绑 onclick，页面「看着能用、点了没反应」。只有带强断言（断言位置从 1/5 变 2/5）的 cdp_features 抓得到；弱断言（「抽屉还开着」）会假绿。
